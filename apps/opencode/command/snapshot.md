Прочитай файл `CONTEXT.md` в корне проекта, если он существует (если нет —
создай новый). Обнови его новым снапшотом текущей сессии, ПОЛНОСТЬЮ
перезаписав содержимое файла (не дописывай в конец, не накапливай старые
версии) — актуальным должен быть только последний срез. Ответь в чате
кратко (1-2 предложения), что обновил, без дублирования содержимого файла.

Формат содержимого CONTEXT.md:

## Session Snapshot [YYYY-MM-DD]

### Цель / контекст
Кратко: что за проект/задача, какая общая цель.

### Текущее состояние
- Что уже сделано (факты, решения, готовые артефакты)
- Что работает / что проверено
- Ключевые решения и почему они были приняты

### Незавершённое
- Что осталось сделать
- На чём остановились (последний шаг перед прерыванием сессии)
- Известные проблемы / баги / вопросы без ответа

### Технический контекст
- Стек, версии, ключевые файлы/пути, структура проекта
- Договорённости по стилю/формату/конвенциям

### Следующий шаг
Один конкретный шаг, с которого нужно продолжить в новой сессии.

### Не повторять
Тупики/подходы, которые уже пробовали и они не сработали.

Требования:
- Пиши плотно, без "воды". Это конспект для машины, не для человека.
- Не пересказывай весь диалог — только то, что нужно для продолжения работы.
- Если раздел неприменим — пропусти его, не пиши "нет данных".
- Если CONTEXT.md уже существовал — учти его прошлое содержимое (не
