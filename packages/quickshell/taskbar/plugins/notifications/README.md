# Notifications

Центр уведомлений поверх mako: история и непрочитанные.

**Бар:** колокольчик у правого края. Серый — всё прочитано; есть новые —
светлый с красной точкой. Клик открывает центр.

## Попап

- **Шапка:** `NOTIFICATIONS` / `3 NEW · 12 TOTAL`, `EMPTY`. Кнопка справа —
  очистить историю.
- **Список** (новые сверху): приложение и время (`HH:mm`, для прошлых дней
  `dd.MM HH:mm`), заголовок (critical — красным), текст до двух строк.
  Пришедшие до открытия центра отмечены красной точкой. Видно
  `Theme.notificationsVisible` записей, дальше прокрутка.

## Как работает

- Показывает уведомления по-прежнему mako (`themes/gruvbox/mako/config`:
  `default-timeout=5000`, `ignore-timeout=1` — 5 секунд для всех,
  `max-history=100`).
- Сервис слушает вызовы `Notify` на сессионной шине (`dbus-monitor`) и после
  каждого читает у mako показанные и историю (`notifications.sh --list`).
- mako хранит историю без времени и не умеет её чистить, поэтому сервис ведёт
  свою: до `Theme.notificationsMax` записей с временем прихода, в
  `statePath("notifications.json")`. CLEAR очищает её.
- Непрочитанные — пришедшие после последнего открытия центра. При первом
  запуске всё, что уже было в mako, считается прочитанным.

## Файлы

| Файл | Что |

| `Notifications.qml` | Бар-модуль: колокольчик и точка |

| `NotificationsPopup.qml` | Попап |
| `scripts/notifications.sh` | `--list`: показанные + история mako |

**IPC:** `qs -c taskbar ipc call notifications toggle` — открыть/закрыть попап.
