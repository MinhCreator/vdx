# cleaner — плагин чистильщика

Значок `trash` в баре. Попап (пересканирует, если скану больше минуты):
сколько можно освободить, шесть самых больших категорий (системные — с
пометкой sudo), **Clean safe** — безопасные категории ваших файлов (кэши,
миниатюры, корзина; без браузеров и без sudo) одним кликом, ↗ — окно
(`apps/cleaner`, Super+X) для остального и режима AI. Данные —
`CleanerService`, IPC попапа — `clean`.
