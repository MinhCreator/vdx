# folder

Папка для модулей, убранных с бара. На баре — значок папки и число модулей в
ней; клик открывает попап с плитками (значок и название), клик по плитке —
попап этого модуля прямо под папкой (у захвата — сам захват).

Что лежит в папке, задаётся в Shell Manager › Bar, строка **FOLDER** (у
каждого бара своя); туда чипы перетаскиваются так же, как в зоны. Модули из
папки живут внутри модуля Folder нулевой ширины и невидимыми — поэтому их
попапы открываются под папкой. Модулю нужна функция `openPopup()`.

| Файл | Что |
|---|---|
| `Folder.qml` | Значок, невидимые модули папки, попап |
| `FolderPopup.qml` | Плитки модулей |
