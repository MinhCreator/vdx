# Shell Manager

Окно настроек оболочки — обычное плавающее окно Hyprland (правило в
`hypr/components/rules.lua`, 820×600). Открывается кнопкой `shell` в баре,
**Super+S** или `qs -c taskbar ipc call shell toggle`; конкретная страница —
`… shell open <appearance|bar>` (старые `themes`, `wallpaper`, `plugins`
ведут туда же). Escape закрывает.

Слева — разделы, справа — страница с прокруткой.

## Разделы

- **Appearance** — то, как выглядит рабочий стол. Слева живое превью (обои,
  бар с иконками в цветах состояний, попап) в цветах выбранной темы, справа
  список тем. Клик по теме только показывает её в превью; **Apply**
  переключает через `install.py theme set`, **Cancel** возвращает. Оболочка
  перекрашивается на лету, без перезапуска: `ThemeService` кладёт палитру
  активной темы в `Theme.live`. Ниже — обои: образец «Theme» (цвет темы,
  `background1`), готовые образцы или свой hex.
- **Bar** — только размещение, группы в одном ритме (заголовок, строки,
  линия):
  - **MONITOR** — **Same bar everywhere** (один бар Main на всех мониторах) или
    вкладки **Main** / **Extra** (Main — внешний монитор, если подключён, иначе
    ноутбук; Extra — ноутбук при подключённом внешнем), **Show bar**;
  - **LAYOUT** — три зоны и под ними **NOT ON THIS BAR**: модули, включённые,
    но не стоящие на этом баре. Значки перетаскиваются между зонами и в эту
    полку; **Copy Main** (на Extra) копирует раскладку Main, **Clear** отправляет всё
    на полку, **Reset** — раскладка по умолчанию;
  - **STYLE** — значки solid / контур, общие для всех баров.
- **Plugins** — слева все плагины (приглушён — выключен), справа выбранный:
  тумблер в строке списка (выключенный плагин пропадает со всех баров и из
  раскладки),
  его опции — `<Name>Settings.qml` (поле `settings` в реестре), значения в
  `config/PluginSettings.qml` (`plugins.json`) — и **Reset** к значениям по
  умолчанию. Сейчас: часы (12h, секунды, дата), батарея / звук / яркость /
  Wi-Fi (число или имя рядом с иконкой), музыка и радио (длина названия),
  уведомления (точка, высота списка), буфер (лимит), захват (папки),
  мониторинг (число в баре, секции попапа).

## Файлы

| Файл | Что |
|---|---|
| `ShellManagerWindow.qml` | Окно (`FloatingWindow`), Escape, IPC `shell` |
| `ShellManager.qml` | Навигация и область страницы |
| `AppearancePage.qml`, `ThemePreview.qml` | Превью, темы, обои; миниатюра темы |
| `Wallpaper.qml` | Заливка обоев через `awww` |
| `BarPage.qml`, `BarChips.qml` | Мониторы, раскладка зон и полка «не на этом баре», стиль значков |
| `PluginsPage.qml` | Список плагинов и страница опций выбранного |
| `ThemeService.qml` | Список тем, палитры (все роли), переключение, `Theme.live` |
| `scripts/themes.sh` | Темы и их цвета по ролям из `Colors.qml` каждой темы |

Опции хранят `config/ShellSettings.qml` (`settings.json`: `solidIcons`,
`wallpaperMode`, `wallpaperColor`), `config/PluginSettings.qml` (`plugins.json`) и `bar/BarLayout.qml` (`layout.json`:
раскладка и выключенные модули по ролям мониторов).
