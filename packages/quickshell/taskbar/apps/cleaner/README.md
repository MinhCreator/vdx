# Cleaner

Чистильщик — своё окно (`FloatingWindow`, 760×620; как открывается — Shell
Manager › Shell apps). **Super+X** или
`qs -c taskbar ipc call cleaner <toggle|open|close>`; Escape закрывает.
Открытие пересканирует, если прошлому скану больше минуты. Коротко то же —
плагин в баре (`plugins/cleaner`).

## Basic

Категории с размером и переключателем (безопасные включены сразу):

- **YOUR FILES** — Trash, миниатюры, сборки yay / paru, кэши pip / npm / uv /
  go / cargo, кэши шейдеров (всё пересобирается само), кэши браузеров
  (выключены: сначала закрыть браузер). Очищаются сразу, содержимое папок.
- **SYSTEM · NEEDS SUDO** — кэш pacman (`paccache -rk1`, `-ruk0`), сироты
  (`pacman -Rns $(pacman -Qdtq)`), журнал (`--vacuum-time=2weeks`), дампы
  падений. Только в терминале: **Clean** открывает kitty с этими командами,
  пароль спрашивает sudo там (графического агента polkit нет — пароль через
  бар не просим).

Внизу — сколько выбрано и **Clean** (с опцией подтверждения — «Sure?»).

## AI

**Analyze** отдаёт Claude (`claude -p`, модель из настроек, без инструментов,
без сохранения сессии, не дороже $0.50) сводку дома: папки трёх уровней от
100 МБ и файлы от 200 МБ — путь, размер, сколько дней не менялись; содержимое
он не видит. Ответ — список «путь · почему · риск». Скрипт оставляет только
пути из этой сводки и никогда — защищённые (`~/.dotfiles`, `.ssh`, `.gnupg`,
`.config`, связки ключей, `.local/state` и их родителей). Отмеченное
(с низким риском — сразу) **Move to Trash** отправляет в корзину (`gio trash`),
жёлтое — Claude не уверен. `claude` запускается без `ANTHROPIC_API_KEY` из
окружения — через вход в аккаунт.

## Настройки

Shell Manager › Plugins › Cleaner (`PluginSettings` "cleaner"): подтверждение,
AI mode вкл / выкл, модель (Haiku / Sonnet).
