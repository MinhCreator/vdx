# Radio

Интернет-радио поверх MPD; станции — `~/.config/scripts/radio/stations.json`
(radio-cli). Воспроизведение — общий `plugins/mpd/MpdService.qml`.

**Бар:** `<Станция> - <трек в эфире>` (без иконки), когда играет радио, иначе
серое `Radio` с иконкой. Клик — попап, средняя кнопка — включить/выключить. С клавиатуры:
`qs -c shell ipc call radio toggle`.

## Попап

- **Шапка:** `Radio`, `ON AIR · <СТАНЦИЯ>` / `OFF`, тумблер — выключить или
  продолжить последнюю станцию (иначе первую).
- **NOW PLAYING** — что сейчас в эфире (название из потока).
- **STATIONS (N)** — список станций; текущая — серая заливка и галочка, у
  запускаемой — спиннер. Клик включает станцию.

## Файлы

| Файл | Что |
|---|---|
| `Radio.qml` | Бар-модуль |
| `RadioService.qml` | Станции, запуск/остановка |
| `RadioPopup.qml` | Попап |

Скрипт — `scripts/music.sh` (`--stations`, `--radio KEY`, `--stop`), см. Music.
Новая станция — запись `"key": { "name", "url" }` в `stations.json`.
