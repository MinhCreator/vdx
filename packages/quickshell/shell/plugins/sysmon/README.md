# sysmon

Метрики системы, только чтение. В баре — загрузка процессора (жёлтая от 70%,
красная от 90%); клик открывает попап.

- **CPU** — общая загрузка, частота, температура и полоска на каждое ядро.
- **MEMORY** — занято / всего, swap.
- **GPU** — частота Intel; NVIDIA — загрузка, память, температура, мощность,
  но только если карта и так не спит: `nvidia-smi` её будит, поэтому спящая
  показывается как «asleep».
- **DISKS** — чтение / запись в секунду, заполненность каждого раздела.
- **NETWORK** — скорость на интерфейсе маршрута по умолчанию.
- **SENSORS** — температуры NVMe и Wi-Fi, обороты вентиляторов (температура
  CPU — в строке CPU).

Бэкенд — `scripts/sysmon.sh`: снимок счётчиков в JSON; проценты и скорости
сервис считает по разнице двух снимков. Для бара — облегчённый `sysmon.sh cpu`
раз в 3 с, при открытом попапе — полный снимок раз в 1.5 с.

| Файл | Что |
|---|---|
| `Sysmon.qml` | Загрузка CPU в баре и попап |
| `SysmonPopup.qml` | Секции метрик |
| `SysmonService.qml` | Снимки, разницы, частота опроса |
