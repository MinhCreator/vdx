# Shell Manager

Окно настроек оболочки — обычное плавающее окно Hyprland (правило в
`hypr/components/rules.lua`, 820×600). Открывается кнопкой `shell` в баре,
**Super+S** или `qs -c shell ipc call shell toggle`; конкретная страница —
`… shell open <appearance|bar>` (старые `themes`, `wallpaper`, `plugins`
ведут туда же). Escape закрывает.

Оформление настроек — правила в `shell/CLAUDE.md` (раздел «Настройки»).

Слева — разделы, справа — страница: шапка раздела (иконка, заголовок,
подзаголовок — `icon` / `title` / `subtitle` страницы) стоит на месте,
прокручивается только то, что под ней. Под открытым разделом —
его группы (`jumps` страницы): клик плавно прокручивает к группе, полоска
слева отмечает ту, что сейчас читается (её заголовок у верха окна; в
конце страницы — последнюю). У Plugins подпунктов нет — там свой список.

## Разделы

- Сверху слева — шапка окна (шестерёнка, **Shell Manager**), на одной линии
  с шапкой раздела.
- **Appearance** — то, как выглядит рабочий стол. Слева живое превью (обои,
  бар с иконками в цветах состояний, попап) в цветах выбранной темы, справа
  список тем. Клик по теме только показывает её в превью; **Apply**
  переключает через `install.py theme set`, **Cancel** возвращает. Оболочка
  перекрашивается на лету, без перезапуска: `ThemeService` кладёт цвета
  активной темы в `Theme.live`. Дальше **ICONS** — стиль значков (контур / залитые) для всей оболочки:
  бар, попапы, окна. Ниже — обои: **Source** выбирает, чем
  залит экран, как Colour у курсора — **Theme** (цвет темы, `background1`),
  **Image** (картинки из `~/.dotfiles/wallpapers`: сначала папка активной
  темы, потом `common/`; клик ставит картинку активной теме — у каждой темы
  своя, превью показывает картинку выбранной темы; **Add image** копирует файл
  по пути в папку темы), **Custom** (готовые образцы и свой `#rrggbb`). Под
  выбором — только то, что нужно этому варианту. Дальше — **FONT**: образец
  текста выбранным шрифтом и список (Nerd Fonts до ~120 МБ и всё
  моноширинное, что уже стоит; не скачанные — со значком загрузки). **Apply** при нужде скачивает шрифт в `~/.local/share/fonts` и
  делает его `monospace` для всей системы: fontconfig
  (`packages/fontconfig/fonts.conf` подключает выбор из
  `~/.local/state/dotfiles/font.conf`), kitty, rofi, mako и swaylock просят
  `monospace`, оболочка берёт `ShellSettings.font`. Шрифт, поставленный после
  старта оболочки, Qt не видит — тогда Apply перезапускает её. **CURSOR** — так же, как шрифт: слева
  превью главных форм (стрелка, рука, текст, ожидание…) выбранного курсора в
  выбранном цвете, справа список, **Apply** при нужде скачивает его в
  `~/.local/share/icons`. **Colour**: Original — как нарисован; Theme — тело
  цветом текста темы, обводка цветом фона, курсор перекрашивается сам при
  смене темы; Custom — свой hex, обводка подбирается контрастной. Цветной
  курсор — копия выбранного с пикселями, переведёнными с чёрно-белого на два
  цвета (`dotfiles-cursor-<fill>-<outline>`, ~2 с). **Size** применяется
  сразу. Всё ставится тут же (`hyprctl setcursor`, gsettings, XDG `default`)
  и при каждом старте Hyprland (`cursors.py restore`).
- **Bar** — группы в одном ритме (заголовок, строки, линия):
  - **MONITOR** — вкладки **Main** / **Extra** (если бары разные), **Same bar
    everywhere** (один бар на всех мониторах; Main — внешний монитор или
    ноутбук без него, Extra — ноутбук при подключённом внешнем), **Show bar**;
  - **LAYOUT** — сверху маленький предпросмотр бара (что не влезло в свою
    половину — «+N»), под ним строки, как строки настроек: слева
    **LEFT · CENTER · RIGHT · FOLDER · HIDDEN** (FOLDER — модули в попапе
    модуля Folder, см. `plugins/folder`), справа чипы «значок + название» в
    порядке на баре, с переносом (чипы Material), между строками тонкие
    линии. Чип тянут вдоль строки, в другую или в HIDDEN
    (тонкая черта — куда встанет). **Same as <монитор>** копирует раскладку
    другого бара, **Reset** — по умолчанию. Новый плагин появляется только на
    Main;
  - **STYLE** — анимация подчёркивания модуля с открытым попапом.
- **Plugins** — только настройки: слева список плагинов, справа опции
  выбранного — его `<Name>Settings.qml` (поле `settings` в реестре), значения в
  `config/PluginSettings.qml` (`plugins.json`) — и **Reset** к значениям по
  умолчанию. Показывать ли плагин и где — страница Bar (строка HIDDEN).
  Сейчас: часы (12h, секунды, дата), батарея / звук / яркость / Wi-Fi (число
  или имя рядом с иконкой), музыка и радио (длина названия), уведомления
  (точка, высота списка), буфер (лимит), захват (папки), мониторинг (число в
  баре, секции попапа).

- **Shell apps** — как открываются собственные окна оболочки (Shell Manager,
  Task Manager). Каждое — одна строка: название и как открывается сейчас
  («floating · 820 × 600 · centred»); клик (или подпункт меню слева)
  разворачивает, другое при этом сворачивается: маленький монитор с окном так, как оно откроется (размер и
  место в масштабе; под курсором — указатель; tiled — половина раскладки) и
  **Open it**, ниже **Window** (Floating / Tiled), для плавающего **Size**
  (Default — свой размер, Preset — Small / Medium / Large как доля экрана,
  Custom — ширина × высота) и **Position**: сетка 3 × 3 (углы, края, центр;
  отступ 12 px, сверху — под баром), **Cursor** (по центру указателя) или
  **Custom** (x, y). Окно всегда остаётся на экране. Варианты применяются
  сразу, числа — по Enter; видно при следующем открытии окна.
  `scripts/shellapps.py` хранит выбор (`~/.local/state/dotfiles/shell-apps.json`),
  пишет из него правила Hyprland (`shell-apps.lua` рядом; их подключает
  `hypr/components/rules.lua`, там же значения по умолчанию) и делает
  `hyprctl reload`.
- **Binds** — бинды Hyprland такими, какие они сейчас действуют
  (`hyprctl binds -j`): поиск по действию, группе и клавишам, группы
  капсом, в строке — что делает и клавиши «клавишами». Группа и имя — из
  описания бинда «Группа · Действие» (`hypr/components/keybinds.lua`,
  функция `bind`); без описания — группа Other. Пронумерованный ряд
  (рабочие столы 1–10) сворачивается в одну строку. Группы — подпункты в
  меню слева. Менять бинды — в `keybinds.lua`.

## Файлы

| Файл | Что |
|---|---|
| `ShellManagerWindow.qml` | Окно (`FloatingWindow`), Escape, IPC `shell` |
| `ShellManager.qml` | Навигация и область страницы |
| `AppearancePage.qml`, `ThemePreview.qml` | Превью, темы, обои; миниатюра темы |
| `Wallpaper.qml` | Обои через `awww`: картинка темы или заливка цветом |
| `WallpaperService.qml`, `WallpaperThumb.qml` | Картинки обоев: выбор для темы, добавление; миниатюра |
| `BarPage.qml`, `BarPreview.qml` | Мониторы, полосы чипов раскладки и предпросмотр бара, анимация подчёркивания |
| `ShellAppsPage.qml`, `ShellAppsService.qml`, `WindowPreview.qml`, `PositionGrid.qml`, `PairRow.qml` | Shell apps: режим, размер и место окон; схема монитора; сетка 3 × 3; строка из двух чисел |
| `BindsPage.qml`, `BindsService.qml` | Бинды Hyprland по группам: `hyprctl binds -j`, сворачивание рядов |
| `PluginsPage.qml` | Список плагинов и страница опций выбранного |
| `ThemeService.qml` | Список тем, их цвета (все роли), переключение, `Theme.live` |
| `FontService.qml`, `scripts/fonts.py` | Шрифты: список, установка, `monospace`, перезапуск оболочки |
| `CursorService.qml`, `scripts/cursors.py` | Курсоры: список, установка, превью, цвет (свой / темы / заданный), размер |
| `ColourRow.qml` | Строка «Custom colour»: образец + поле `#rrggbb`, Enter применяет (обои, курсор) |
| `WheelGuard.qml` | Колесо над списком крутит только список, страница не перехватывает |
| `PickList.qml` | Рамочный список со значками «текущий / качается / скачать» |
| `scripts/themes.sh` | Темы и их цвета по ролям из `Colors.qml` каждой темы |

Опции хранят `config/ShellSettings.qml` (`settings.json`: `solidIcons`,
`underlineAnimation`, `font`, `wallpaperMode`, `wallpaperColor`,
`wallpaperImages`), `config/PluginSettings.qml` (`plugins.json`) и `bar/BarLayout.qml` (`layout.json`:
раскладка и выключенные модули по ролям мониторов).
