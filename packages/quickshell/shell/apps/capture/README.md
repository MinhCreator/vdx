# Capture

Захват экрана. **Super+Shift+S** (или камера в баре, или `qs -c shell ipc
call capture open`) замораживает все экраны и показывает панель в стиле
попапов: шапка с текущим выбором и ✕, **WHAT** (Region / Window / Screen),
**AS** (Screenshot / Recording), для скриншота — куда сохраняется, для записи
— **SOUND**, **FRAME RATE**, **QUALITY**, **ENCODER** рядами кнопок, внизу
тумблер **Hide cursor**. Esc или правый клик — отмена. Во время записи тот же
хоткей или клик по таймеру в баре останавливает её.

- **Screenshot** — вырезается из замороженного кадра в полном разрешении,
  кладётся в буфер (`wl-copy`) и в `~/Pictures/Screenshots`, уведомление с
  превью.
- **Recording** — `gpu-screen-recorder` в `~/Videos/Recordings`. Encoder
  **Auto**: от сети — любая видеокарта, от батареи — только встроенная
  (рекордер видит одну Mesa и не будит NVIDIA). Нет VAAPI — кодирует
  процессор.
- **SAVE** (в панели и в Shell Manager › Plugins › Capture): скриншот —
  **Folder** (в папку), **Ask** (окно «Save as» с путём: Enter — сохранить,
  Esc — оставить только в буфере), **Clipboard** (только буфер, на диск ничего);
  запись — **Folder** или **Ask** (спросит при остановке; Esc — в папку по
  умолчанию, запись не теряется). Пока ответа нет, файл лежит в
  `~/.cache/quickshell-capture`. Скриншот в буфер попадает всегда.
- Каждый раз открывается в Region / Screenshot со скрытым курсором; настройки
  записи запоминаются (`capture.json` в state-папке), папки — в Shell
  Manager › Plugins › Capture.

## Без мерцания и без второго курсора

Открытие по шагам. Оверлеи создаются прозрачными и снимают кадр с курсором.
Снимок экрана в Hyprland — копия последнего отрисованного кадра, программный
курсор (NVIDIA) уже в нём, поэтому курсор прячется (`cursor:invisible`), а
оверлей каждый кадр перерисовывает себя, чтобы Hyprland перерисовывал экран.
Hyprland применяет `invisible` не сразу — при следующем событии клавиатуры
или по таймеру раз в 500 мс (`IHyprRenderer::ensureCursorRenderingMode`), —
поэтому кадр без курсора проверяется: участок 24×24 под курсором сравнивается
с кадром с курсором (Canvas), и пока они совпадают, кадр переснимается
(каждые 40 мс, до 20 раз). Потом курсор возвращается, оверлеи становятся
видимыми, а через пару кадров попапы бара прячутся (`PopupManager.frozen`) —
на снимке они уже есть. Закрытие — в обратном порядке. Hide cursor выбирает,
какой из двух кадров показан и сохранён.

Проверено серией: 30 открытий с курсором в случайных точках обоих мониторов —
30 чистых кадров, в 23 случаях первая попытка была с курсором и переснята.

## Файлы

| Файл | Что |
|---|---|
| `CaptureService.qml` | Состояние, шаги открытия, сохранение, запись, IPC `capture` |
| `CaptureOverlay.qml` | Оверлей на экран: кадры, затемнение, выбор цели, обрезка |
| `CaptureToolbar.qml` | Панель: что и как снимать, настройки записи, курсор |
| `CaptureRecording.qml` | Плашка записи в углу: время, Stop, куда сохранится |
| `CaptureSave.qml` | Окно «Save as» для режима Ask |
