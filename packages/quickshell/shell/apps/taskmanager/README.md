# Task Manager

Диспетчер задач — своё окно (`FloatingWindow`, 780×600; как оно открывается —
плавающим или в раскладке, размер, место — Shell Manager › Shell apps). **Super+D** или
`qs -c shell ipc call taskmanager <toggle|open|close>`. Escape сначала
очищает поиск, потом закрывает.

- Шапка: число программ / процессов, частота обновления, поиск (по имени,
  pid и командной строке).
- CPU, память, GPU (NVIDIA, когда она не спит, иначе доля частоты Intel) и
  сеть (↓ приём, ↑ отдача) за последние две минуты: у каждого свой график
  (`LoadGraph`: линия 2px над бледной заливкой, своя шкала, без сетки);
  подпись — значение сейчас, при наведении — в той точке («· 14s ago»);
  жёлтые от 70 %, красные от 90 %. GPU и сеть — из `SysmonService`
  (держит полный опрос, пока окно или попап открыты).
- Таблица: программа (или процесс), пользователь, число процессов (или pid),
  CPU, память. Клик по заголовку CPU / MEMORY / PROGRAM сортирует.
  CPU — доля всех ядер между двумя обновлениями (0–100 %), память — RSS.
- Внизу — выбранная строка (процессы, потоки, команда) и **End** (TERM) /
  **Kill** (KILL) для всех её процессов. С опцией «Ask before ending» первый
  клик превращает кнопку в «Sure?» на 3 с. Чужой процесс (root) не
  завершить — ошибка внизу.
- Клавиши: ↑ ↓ PgUp PgDn — выбор, Delete — End, Shift+Delete — Kill,
  Ctrl+F или `/` — поиск.

Процессы опрашиваются только пока окно (или попап плагина в баре —
`plugins/taskmanager`) открыто.

## Настройки

Shell Manager › Plugins › Task manager (`PluginSettings` "taskmanager";
плагин `taskmanager` в реестре `BarLayout`):
группировка по программе, только мои процессы, потоки ядра, сортировка,
частота обновления (1 / 2 / 5 с), подтверждение перед завершением.

## Файлы

| Файл | Что |
|---|---|
| `TaskManagerWindow.qml` | Окно, Escape, IPC `taskmanager` |
| `TaskManager.qml` | Шапка, графики CPU / памяти / GPU / сети, таблица, End / Kill, клавиши |
| `LoadGraph.qml` | Спарклайн истории: линия, заливка, перекрестие при наведении |
| `TaskManagerService.qml` | Опрос, фильтр, группировка, сортировка, завершение |
| `TaskManagerSettings.qml` | Страница опций в Shell Manager |
| `scripts/tasks.py` | `list` (из `/proc`, CPU по снимку в `~/.cache/dotfiles/tasks.json`), `kill <TERM|KILL> <pid>…` |
