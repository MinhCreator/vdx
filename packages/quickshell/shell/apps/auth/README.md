# Auth — панель root и polkit-агент оболочки

Одна панель в стиле попапа выезжает сверху на мониторе в фокусе, под баром,
и держит клавиатуру, пока видна. Три вида:

- **Подтверждение** — root-действие самой оболочки (`RootService.request`):
  заголовок, кто просит, шаги словами (что именно затронет: какие пакеты,
  сколько дампов) с точной командой под каждым. **Run** (Enter) / **Cancel**
  (Escape). Показывается **каждый раз**.
- **Пароль** — polkit спрашивает: после нашего Run в первый раз — в той же
  панели под шагами; запрос любой другой программы (`pkexec`, `systemctl`…) —
  с её текстом. Пароль скрыт квадратиками; неверный — красная строка и запрос
  снова.
- **Выполнение** — спиннер на Run, пока идёт.

`RootService` сам запускает `pkexec /bin/bash -c <скрипт>` из процесса
оболочки. С правилом `system/etc/polkit-1/rules.d/50-pkexec-keep.rules`
(`AUTH_ADMIN_KEEP` для `pkexec` у wheel в своей сессии) polkit помнит пароль
5 минут для процесса, вызвавшего `pkexec`, — для оболочки: дальше панель
подтверждения без пароля. Ставится `./install.py system install`.

| Файл | Что |
|---|---|
| `AuthPrompt.qml` | `PolkitAgent` + панель (`PanelWindow` слоя Overlay, `KitFrame` выезжает) |
| `RootService.qml` | Очередь из одного root-действия: `request`, `run`, `cancel`, `finished` |

Новому root-действию оболочки: шаги `[{label, what, command}]` и скрипт —
в `RootService.request(источник, заголовок, шаги, скрипт, метка)`, результат —
сигнал `finished(метка, ok, ошибка)`. `sudo` в терминале сюда не относится —
он спрашивает в терминале.
