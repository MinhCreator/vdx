# taskmanager — модуль диспетчера задач

Значок в баре (`activity`, красный при загрузке CPU от 90 %, пока попап
открыт). Попап — коротко то, что в окне диспетчера (`apps/taskmanager`):

- шапка: число процессов, группировка; кнопка ↗ открывает окно (Super+D);
- CPU, память и GPU полосами (жёлтые от 70 %, красные от 90 %), сеть ↓ / ↑;
- самые занятые программы (сортировка — как в окне), у каждой — ✕ End
  (TERM всем её процессам; с опцией подтверждения второй клик — «✓»).

Данные и действия — `TaskManagerService` (опрос, пока открыт попап или окно).
Опции — Shell Manager › Modules › Task manager (`apps/taskmanager/TaskManagerSettings.qml`),
для попапа — POPUP › Programs listed (3 / 5 / 8). IPC попапа — `tasks`.
