# clipboard

История буфера обмена. Иконка в баре или **Super+B** (`qs -c shell ipc call
clipboard toggle`) открывает попап.

- Всё скопированное — текст и картинки — новое сверху; повтор поднимается
  наверх. Пароли из менеджеров паролей (`x-kde-passwordManagerHint`) не
  сохраняются.
- Клик копирует запись обратно (в заголовке мелькает зелёное COPIED, попап
  закрывается), × на месте времени при наведении удаляет. Текст и картинку
  можно перетащить из списка в другое приложение; картинка — обычный
  PNG-файл.
- Поиск по тексту, **Keep last** — лимит записей (25–500), **Clear** — очистить
  (второй клик подтверждает).

Бэкенд — `scripts/clipboard.sh`: `wl-paste --watch` на всю сессию кладёт
каждую запись файлом в `$XDG_DATA_HOME/clipboard/`.

| Файл | Что |
|---|---|
| `Clipboard.qml` | Иконка в баре и попап |
| `ClipboardPopup.qml` | История, поиск, лимит, очистка |
| `ClipboardService.qml` | Наблюдатель `wl-paste`, список, действия |
